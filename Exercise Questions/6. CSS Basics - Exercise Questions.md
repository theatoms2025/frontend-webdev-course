## Question 1
Create & Style with Color Formats

Create a simple HTML page with:
• A main heading, a subheading, and a paragraph of text.
• Use an external CSS file to:
  ○ Change the background color of the entire page.
  ○ Set different colors for the heading, subheading, and paragraph using different color formats: e.g., named color (red), hexadecimal (#00FF00), RGB (rgb(0, 0, 255)), or HSL (hsl(60, 100%, 50%)).
• Add comments in your CSS selection so you can choose each color.

## Question 2
Apply & Compare CSS Methods

Create an HTML page with:
• A heading (h1), a paragraph, and a button.
• Then, style them using three different CSS application methods:
  1. Use an inline style to set the color of the heading.
  2. Use an internal <style> block in the HTML file to set the background color of the paragraph.
  3. Use an external CSS file to style the button (e.g., change its background color and text color).
• Finally, add comments in your HTML file explaining which CSS method you used for each element and why.

## Question 3
Color & Readability Challenge

Create a small webpage with two paragraphs:
• Use CSS to set the background color and text color for each paragraph.
• Experiment with both high and low contrast color combinations.
• Ensure good readability: adjust colors until the text is comfortable to read.
• Add CSS comments explaining why some color choices create better readability than others.
