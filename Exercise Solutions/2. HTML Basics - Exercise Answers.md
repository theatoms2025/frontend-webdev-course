# HTML Basics - Exercise Solutions

## Question 1
Let's start simple
"Hello World! This is my first web page."
Hint: Use the appropriate tags that browsers recognize for paragraphs.

### Answer

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Solution Q1</title>
</head>
<body>
    <p>Hello World! This is my first web page.</p>
</body>
</html>
```

## Question 2
Headings vs Paragraphs – Know the Difference
Organize the following content using proper HTML headings and paragraph tags:
- Main website title: TheAtoms
- Section title: Frontend Web Development
- Subsection: React
- Description: "Hey! I am a paragraph."

### Answer

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Solution Q2</title>
</head>
<body>
    <h1>TheAtoms</h1>
    <h2>Frontend Web Development</h2>
    <h3>React</h3>
    <p>Hey! I am a paragraph.</p>
</body>
</html>
```

## Question 3
Link It Up!
Create a clickable link on your page that opens Google when clicked.
Use the actual URL: https://www.google.in
Bonus: Make it open in a new tab!

### Answer

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Solution Q3</title>
</head>
<body>
    <a href="https://www.google.in" target="_blank">Visit Google</a>
</body>
</html>
```

## Question 4
Create a Morning Routine Checklist
Display your morning routine using an HTML ordered list.
- Wake up
- Brush teeth
- Take a shower
- Eat breakfast
- Start coding
Challenge: Modify the list so it starts from 5 using the appropriate HTML attribute.

### Answer

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Solution Q4</title>
</head>
<body>
    <h2>Morning Routine Checklist</h2>
    <ol>
        <li>Wake up</li>
        <li>Brush teeth</li>
        <li>Take a shower</li>
        <li>Eat breakfast</li>
        <li>Start coding</li>
    </ol>
    
    <h3>Challenge - Starting from 5:</h3>
    <ol start="5">
        <li>Wake up</li>
        <li>Brush teeth</li>
        <li>Take a shower</li>
        <li>Eat breakfast</li>
        <li>Start coding</li>
    </ol>
</body>
</html>
```

## Question 5
Add Audio to Your Webpage
You want to share your favorite song or sound clip on your personal webpage.
Use the <audio> tag in HTML to embed an audio file with playback controls.
Bonus: Add a heading above the audio that says: Listen to My Favorite Track.

### Answer

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Solution Q5</title>
</head>
<body>
    <h2>Listen to My Favorite Track</h2>
    <audio controls>
        <source src="favorite-song.mp3" type="audio/mpeg">
        <source src="favorite-song.ogg" type="audio/ogg">
        Your browser does not support the audio element.
    </audio>
</body>
</html>
```
