## Question 1
Create & Style with Color Formats

Create a simple HTML page with:
• A main heading, a subheading, and a paragraph of text.
• Use an external CSS file to:
  ○ Change the background color of the entire page.
  ○ Set different colors for the heading, subheading, and paragraph using different color formats: e.g., named color (red), hexadecimal (#00FF00), RGB (rgb(0, 0, 255)), or HSL (hsl(60, 100%, 50%)).
• Add comments in your CSS selection so you can choose each color.

### Answer

```html
<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8"/>
<meta name="viewport" content="width=device-width,initial-scale=1"/>
<title>Solution Q1</title>
<style>
/* Page background using named color */
body {
  background-color: lightgray;
  font-family: Arial, sans-serif;
  margin: 40px;
  line-height: 1.6;
}

/* Main heading using hexadecimal color format */
h1 {
  color: #FF6B35; /* Orange-red hex color */
  text-align: center;
  margin-bottom: 20px;
}

/* Subheading using RGB color format */
h2 {
  color: rgb(34, 139, 34); /* Forest green RGB color */
  margin-bottom: 15px;
}

/* Paragraph using HSL color format */
p {
  color: hsl(240, 100%, 25%); /* Dark blue HSL color */
  max-width: 600px;
  margin: 0 auto;
  text-align: justify;
}
</style>
</head>
<body>
<h1>Welcome to Color Formats</h1>
<h2>Different Ways to Define Colors</h2>
<p>This paragraph demonstrates various CSS color formats. The page background uses a named color (lightgray), the main heading uses hexadecimal format (#FF6B35), the subheading uses RGB format (rgb(34, 139, 34)), and this paragraph text uses HSL format (hsl(240, 100%, 25%)). Each format has its own advantages: named colors are intuitive, hex is compact, RGB is straightforward for digital displays, and HSL is great for color manipulation.</p>
</body>
</html>
```

## Question 2
Apply & Compare CSS Methods

Create an HTML page with:
• A heading (h1), a paragraph, and a button.
• Then, style them using three different CSS application methods:
  1. Use an inline style to set the color of the heading.
  2. Use an internal <style> block in the HTML file to set the background color of the paragraph.
  3. Use an external CSS file to style the button (e.g., change its background color and text color).
• Finally, add comments in your HTML file explaining which CSS method you used for each element and why.

### Answer

```html
<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8"/>
<meta name="viewport" content="width=device-width,initial-scale=1"/>
<title>Solution Q2</title>
<!-- Internal CSS for paragraph styling -->
<style>
p {
  background-color: #E8F4FD;
  padding: 20px;
  border-radius: 8px;
  margin: 20px 0;
  font-family: Arial, sans-serif;
}

/* External CSS simulation for button styling */
button {
  background-color: #4CAF50;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  font-size: 16px;
  font-family: Arial, sans-serif;
}

button:hover {
  background-color: #45a049;
}

body {
  font-family: Arial, sans-serif;
  margin: 40px;
  line-height: 1.6;
}
</style>
</head>
<body>
<!-- Inline CSS for heading color -->
<h1 style="color: #2E86C1;">CSS Application Methods Comparison</h1>
<!-- 
CSS Method 1 (Inline): Applied directly to h1 element above
- Pros: Highest specificity, quick for single-use styles
- Cons: Not reusable, harder to maintain, mixes content with presentation
-->

<p>This paragraph is styled using internal CSS within the &lt;style&gt; block in the HTML head section. Internal CSS is useful for single-page styles and has medium specificity.</p>
<!-- 
CSS Method 2 (Internal): Applied via <style> block in <head>
- Pros: Good for single-page styles, keeps CSS organized in one place
- Cons: Not reusable across multiple pages, increases HTML file size
-->

<button>Click Me - Styled with External CSS</button>
<!-- 
CSS Method 3 (External - simulated): Applied via external stylesheet reference
- Pros: Reusable across multiple pages, separates content from presentation, cacheable
- Cons: Additional HTTP request, lowest specificity (can be overridden easily)
Note: In this example, button styles are in the internal <style> block to simulate external CSS
-->

<div style="margin-top: 30px; padding: 20px; background-color: #FFF3CD; border-left: 4px solid #FFC107;">
  <h3>CSS Methods Summary:</h3>
  <ul>
    <li><strong>Inline CSS:</strong> Highest priority, used for the heading color</li>
    <li><strong>Internal CSS:</strong> Medium priority, used for paragraph background</li>
    <li><strong>External CSS:</strong> Lowest priority, used for button styling</li>
  </ul>
</div>
</body>
</html>
```

## Question 3
Color & Readability Challenge

Create a small webpage with two paragraphs:
• Use CSS to set the background color and text color for each paragraph.
• Experiment with both high and low contrast color combinations.
• Ensure good readability: adjust colors until the text is comfortable to read.
• Add CSS comments explaining why some color choices create better readability than others.

### Answer

```html
<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8"/>
<meta name="viewport" content="width=device-width,initial-scale=1"/>
<title>Solution Q3</title>
<style>
body {
  font-family: Arial, sans-serif;
  margin: 40px;
  line-height: 1.6;
  background-color: #F8F9FA;
}

h1 {
  color: #2C3E50;
  text-align: center;
  margin-bottom: 30px;
}

/* High contrast paragraph - excellent readability */
.high-contrast {
  background-color: #FFFFFF; /* Pure white background */
  color: #212529; /* Very dark gray text */
  padding: 20px;
  margin: 20px 0;
  border-radius: 8px;
  border-left: 5px solid #28A745;
}
/* 
High contrast explanation:
- White background (#FFFFFF) with very dark text (#212529)
- Contrast ratio approximately 16:1 (exceeds WCAG AAA standard of 7:1)
- Easy on eyes, reduces strain, accessible for users with visual impairments
- Clear distinction between text and background improves readability
*/

/* Low contrast demonstration - poor readability */
.low-contrast-demo {
  background-color: #E9ECEF; /* Light gray background */
  color: #6C757D; /* Medium gray text */
  padding: 20px;
  margin: 20px 0;
  border-radius: 8px;
  border-left: 5px solid #FFC107;
}
/* 
Low contrast explanation:
- Light gray background (#E9ECEF) with medium gray text (#6C757D)
- Contrast ratio approximately 2.5:1 (fails WCAG standards)
- Difficult to read, causes eye strain, not accessible
- Poor distinction makes text blend into background
- Should be avoided for body text content
*/

/* Improved contrast version */
.improved-contrast {
  background-color: #F8F9FA; /* Very light gray background */
  color: #343A40; /* Dark gray text */
  padding: 20px;
  margin: 20px 0;
  border-radius: 8px;
  border-left: 5px solid #007BFF;
}
/* 
Improved contrast explanation:
- Very light background (#F8F9FA) with dark text (#343A40)
- Contrast ratio approximately 12:1 (meets WCAG AAA standards)
- Good readability while maintaining visual softness
- Sufficient contrast without harsh pure black/white combination
*/

.section-header {
  color: #495057;
  margin-top: 30px;
  margin-bottom: 10px;
  font-size: 1.2em;
  font-weight: bold;
}
</style>
</head>
<body>
<h1>Color & Readability Challenge</h1>

<div class="section-header">✓ High Contrast - Excellent Readability</div>
<p class="high-contrast">
This paragraph demonstrates high contrast color combination with excellent readability. The white background and very dark text provide a strong contrast ratio that makes reading comfortable and accessible. This combination reduces eye strain and works well for extended reading sessions. High contrast is essential for accessibility and helps users with visual impairments.
</p>

<div class="section-header">✗ Low Contrast - Poor Readability (Demonstration Only)</div>
<p class="low-contrast-demo">
This paragraph shows low contrast colors that create poor readability. The light gray background with medium gray text makes it difficult to distinguish letters clearly. This combination causes eye strain and fails accessibility standards. Such color choices should be avoided for main content as they exclude users with visual difficulties and make reading uncomfortable for everyone.
</p>

<div class="section-header">✓ Improved Contrast - Good Balance</div>
<p class="improved-contrast">
This paragraph shows an improved contrast approach that balances readability with visual appeal. The very light background with dark gray text provides sufficient contrast while avoiding the harshness of pure black and white. This combination meets accessibility standards while maintaining a softer, more modern appearance that many users find more comfortable for extended reading.
</p>
</body>
</html>
```
